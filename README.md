# CSFloat арбитраж-бот для Telegram

Телеграм-бот, который следит за листингами скинов на **CSFloat**, анализирует
их и присылает выгодные сделки: где можно купить дёшево и перепродать дороже —
либо обратно на CSFloat по средней цене, либо на **market.csgo** — с учётом
комиссий, ликвидности и стабильности флоата.

## Что и как считает бот

Для каждого активного `buy_now` листинга на CSFloat:

| Показатель | Откуда берётся |
|---|---|
| **Цена покупки** | `price` листинга на CSFloat |
| **Средняя цена продажи на CSFloat** | `reference.predicted_price` — оценка справедливой цены самим CSFloat |
| **Цена продажи на market.csgo** | публичный прайс-лист `api/v2/prices/USD.json` |
| **Ликвидность** | `volume` на market.csgo + `reference.quantity` на CSFloat |
| **Стабильность флоата** | расстояние флоата до границы износа (у границы цена скачет) |

Прибыль по каждому пути = `цена_продажи × (1 − комиссия) − цена_покупки`.
Бот берёт **лучший** из двух путей и показывает сделку, только если она:

- прибыльна выше порогов (в % и в $),
- ликвидна (объёмы выше минимумов),
- стабильна по флоату (не у границы износа),
- цена покупки в заданном диапазоне.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:

1. `TELEGRAM_BOT_TOKEN` — получи у [@BotFather](https://t.me/BotFather).
2. `TELEGRAM_CHAT_ID` — свой ID узнай у [@userinfobot](https://t.me/userinfobot).
   Нужен для авто-оповещений.
3. (Опционально) `CSFLOAT_API_KEY`, `MARKET_CSGO_API_KEY` — повышают лимиты
   и стабильность доступа. Без них бот работает на публичных эндпоинтах.

Остальные параметры (пороги прибыли, комиссии, фильтры ликвидности) настроены
разумно по умолчанию — правь под себя в `.env`.

## Запуск

```bash
python main.py
```

Бот начнёт опрашивать CSFloat каждые `SCAN_INTERVAL` секунд и присылать новые
выгодные сделки в чат `TELEGRAM_CHAT_ID`.

## Команды в Telegram

| Команда | Что делает |
|---|---|
| `/start`, `/help` | справка |
| `/scan` | показать лучшие сделки прямо сейчас |
| `/status` | состояние бота, кэш прайс-листа, ключи |
| `/settings` | текущие фильтры |

## Настройка фильтров (`.env`)

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `SCAN_INTERVAL` | интервал авто-скана, сек | 60 |
| `SCAN_LIMIT` | листингов за проход (≤50) | 50 |
| `SCAN_SORT_BY` | `most_recent` / `lowest_price` / `highest_discount` | most_recent |
| `MIN_PROFIT_PERCENT` | мин. прибыль, % | 10 |
| `MIN_PROFIT_ABS` | мин. прибыль, $ | 0.5 |
| `MIN_BUY_PRICE` / `MAX_BUY_PRICE` | диапазон цены покупки, $ (0 = ∞) | 1 / 0 |
| `MIN_MARKET_VOLUME` | мин. объём на market.csgo | 20 |
| `MIN_CSFLOAT_QUANTITY` | мин. кол-во листингов на CSFloat | 10 |
| `FLOAT_EDGE_MARGIN` | отступ флоата от границы износа | 0.01 |
| `CSFLOAT_FEE` / `MARKET_CSGO_FEE` | комиссии (доля) | 0.02 / 0.05 |

## Структура проекта

```
main.py                  — точка входа
config.py                — конфиг из .env
scanner.py               — сбор данных + прогон анализа, дедуп оповещений
sources/
  csfloat.py             — клиент CSFloat (листинги)
  market_csgo.py         — клиент market.csgo (прайс-лист, кэш)
analysis/
  arbitrage.py           — расчёт прибыли и путей перепродажи
  liquidity.py           — ликвидность и стабильность флоата
bot/
  telegram_bot.py        — команды + фоновый авто-скан
  formatters.py          — оформление сообщений
```

## Важно

- Комиссии и `predicted_price` — оценки; перед реальной покупкой сверяйся с
  актуальными ценами на площадках. Учитывай трейд-локи и время вывода.
- Соблюдай лимиты API площадок. При частых запросах используй API-ключи.
- Бот — инструмент аналитики, а не финансовый совет.
